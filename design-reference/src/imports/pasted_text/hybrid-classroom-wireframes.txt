Design a mid-fidelity wireframe prototype (grayscale only, no color) 
for a WebRTC-based Hybrid Classroom Videoconferencing Platform with 
Attention Detection ("PDVSPAHCDDA"), built on Twilio Video infrastructure.

The design must cover all 38 User Stories across 8 Epics listed below. 
Use clean wireframe style: gray fills, white backgrounds, placeholder 
boxes for video tiles, standard UI components (buttons, inputs, icons 
as simple shapes), and Figma auto-layout.

## DESIGN CONSTRAINTS

- Style: Mid-fidelity wireframe. Grayscale only (white, #F5F5F5, 
  #E0E0E0, #9E9E9E, #424242, #000000). No color fills.
- Typography: Use a single sans-serif font (Inter or similar). 
  Hierarchy via size and weight only.
- Video tiles: Represented as gray rectangles with a camera icon and 
  participant name label. No actual images.
- Charts: Skeleton line/bar chart shapes. Labeled axes, no real data.
- Icons: Simple outline icons or basic geometric shapes. No icon 
  libraries required.
- Spacing: 8px grid. Consistent padding of 16px inside panels.
- Annotations: Add a small label on each UI element indicating which 
  US it satisfies (e.g., "[US24]" as a small tag below the component). 
  This is for design review, not production UI.
- Responsive target: Desktop (1440px wide layout). No mobile required.
- Infrastructure note: All video tile areas and transmission-related 
  UI elements should carry a small "Twilio Video" label in the corner 
  to reflect the underlying WebRTC SFU infrastructure.
